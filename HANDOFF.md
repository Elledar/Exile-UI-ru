# HANDOFF — русский языковой пакет для Exile UI

## Готово
- Пакет = папка `ru/` (без форка). Сборка и установка: `python tools/build_all.py "D:/Downloads/PoE_UI/Exile-UI-main"` — всё из эталона `base/english` (Exile UI 16501, base/version.json).
- Этап 1 `ru/client.txt` (журнал русского клиента) и этап 2 названия локаций/камней (`tools/build_names_ru.py`, RePoE в .tmp/repoe) — проверены в игре. Шрифт Fontin Sans CR SC (data\alt_font_FontinSansCR-SC.ttf, в git нет; без него — шрифт Windows, решили оставить как есть).
- Этап 3а: гайд PoE 1, 10 актов (`tools/guide_poe1_ru*.json` → `build_guide_ru.py`, проверяет пробелы в метках — внутри `(quest:…)` только `_`), квесты (`quest_names_ru.json`), 26 подсказок (`hints_ru.json`). В игре проверен акт 1, включая «судовую_аптечку».
- Этап 3б: окна акт-трекера/акт-декодера (`tools/ui_ru.json` → `build_ui_ru.py`), 83 подсказки (`help_tooltips_ru.json`). Короткие кнопки настроек проверены в игре (окно ~677px ≈ английское): загр., ред., сброс, шрифт:, прозрачн.:, общее:, интерфейс:, снаряжение, листание, автотрек, побочное, кв. камней.
- Этап 4: `python tools/check_update.py "<Exile UI>"` — отчёт об изменениях после обновления программы, ⚠ опасные места; `--accept` (с ⚠ — `--accept --force` после правки таблиц) обновляет эталон. Пользователь будет говорить «Exile UI обновилась» — запускаю сам.
- GitHub (публичный): https://github.com/Elledar/Exile-UI-ru, ветка main; релиз v16501 с архивом (`tools/make_release.py "<Exile UI>"` → .tmp/release). Анонс: тема №835 https://github.com/Lailloken/Exile-UI/discussions/835 (англ.+рус., упомянут XaksFlaX).
- В коммитах только noreply-адрес (настроен в .git/config); `backlog-attachments/` не публикуется (.gitignore). Push — только после прямого «да».
