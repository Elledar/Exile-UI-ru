# HANDOFF — русский языковой пакет для Exile UI

## Готово
- Пакет = папка `ru/` (без форка). Сборка+установка: `python tools/build_all.py "D:/Downloads/PoE_UI/Exile-UI-main"` (эталон `base/english`, Exile UI 16501). Переводы: `tools/ui_ru.json` (UI.txt, ключ → значения по порядку повторов, null = английское), `tools/help_tooltips_ru.json` (подсказки), гайд `tools/guide_poe1_ru*.json`.
- Этапы 1–4 (client.txt, названия локаций/камней, гайд PoE 1 на 10 актов, акт-трекер/декодер, `check_update.py` после обновлений — «Exile UI обновилась» → запускаю сам) — готовы, проверены в игре.
- GitHub (публичный): https://github.com/Elledar/Exile-UI-ru, релиз v16501 (`tools/make_release.py`). Тема №835 https://github.com/Lailloken/Exile-UI/discussions/835 — на 2026-11-10 ответов нет. Push — только после прямого «да».
- Меню настроек, переведено в этой сессии (всё собрано и закоммичено):
  - названия функций ms_* (левая колонка; ширину меряли шрифтом через Pillow, предел ≈ «sanctum planner») — проверено в игре; подсказки к 7 верхним значкам;
  - «общее» (шестерёнка) + подсказки — проверено в игре; «клиент игры» (значок PoE) + подсказки — видимая часть проверена, разрешение пользователь трогать не хочет;
  - «клавиши» + 10 подсказок — в игре не проверено; «метки экрана» (screen-checks) + 11 подсказок + 14 инструкций калибровки (раздел `screenchecks`) + подсказки снимка экрана — в игре не проверено;
  - «новости» и «обновление» (updater) + 10 подсказок — в игре не проверено (тексты новостей/изменений приходят с GitHub на английском; кнопки «get hotfix/dev build» зашиты в код). «донат»: всё зашито в код (кнопки, благодарности, имена), переведена только подсказка «more info». Акт-декодер: добавлены общие «клавиша:/своя клавиша:», «масштаб:», global_update («проверить обновления»). «аддоны» переведены вслепую (раздел виден, только если есть папка add-ons). Следующая — «синдикат».
- Термины (выбор пользователя): омни-кей, виджет-кей, меню-кей, рестарт-кей, мув-кей, «виджет меню», exclusive = «перехват», cal = «калибр.», test = «тест», variance = «допуск», tldr-tooltips = «разбор модов», betrayal = «синдикат», enchant finder = «намазки».
- В гайде 9 строк с оранжевой пометкой `(color:ff8000)[проверить_перевод!]` (CHECK_MARK в build_guide_ru.py пропускает её мимо проверки меток).

## В работе
- Ждём от пользователя названия из игры (по пометкам в гайде): решётка в Трущобах, шаткая свеча в Библиотеке (а3); рычаг ×2 (а4), тележки с топливом и маяк (а6), картографическое устройство (а7), тайник контрабандистов (а8), сундук в пустыне Ваштири (а9). Получив — заменить слово и убрать пометку.
- Сверить с русским клиентом: «сехемы»/«карта испытания сехем» (PoE 2), «торговля (продажа/покупка)», «поиск торговли», runeshaping (оставлен английским), «клоны окон» (временно).
- Возможна теснота: «фон вокруг / панель задач / сверху/снизу» на странице клиента (запас — «частично»).
