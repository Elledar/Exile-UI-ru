# HANDOFF — русский языковой пакет для Exile UI

## Готово
- Пакет = папка `ru/` (без форка). Сборка: `python tools/build_all.py`; эталон `base/english` = Exile UI 1.66.0 (16600), принят 2026-11-16 (в 1.66.0 добавлены новые явные моды карт map-info и секция нитей stash-ninja; добавлены переводы для редких окон и исправлены оставшиеся null). Переводы: `tools/ui_ru.json` (ключ → значения по порядку повторов, null = английское), `tools/help_tooltips_ru.json`, гайд `tools/guide_poe1_ru*.json`. После обновления программы: `tools/check_update.py` (отчёт) → правка таблиц → `--accept` → build_all.
- Этапы 1–4 (client.txt, локации/камни, гайд PoE 1 на 10 актов, акт-трекер/декодер) проверены в игре. GitHub https://github.com/Elledar/Exile-UI-ru; тема https://github.com/Lailloken/Exile-UI/discussions/835.
- Меню настроек: функции ms_*, «общее», «клиент игры» (проверены в игре); «клавиши», «метки экрана», «новости/обновление», «донат» (только подсказка), «аддоны» (вслепую): в игре не проверены.
- 2026-11-16, переход на 1.66.0:
  - `client.txt`: добавлены `items_rareonly` («Только для редких») и `items_deliriumreward` («Тип награды Делириума:»);
  - `UI.txt`: добавлена вкладка `m_stash_threads` («нити»); переведены редкие окна `msg_langswitch`, `msg_badresolution`, `msg_restart`, `msg_shutdown`, `msg_proceed`, `global_warning`, `m_permission_restart`, `m_hotkeys_ckey2`, `m_addons_leftover`, `m_addons_importfail`, `m_addons_disable`, `global_league_umbra`; закрыты оставшиеся `null` в `global_delete[2]` («удалено») и `global_skilltree[1]` («деревья умений»);
  - `gems.json`: добавлен русский перевод камня 3.30 `arcane link` — «Чародейская связь» (сверено с poedb.tw/ru);
  - гайд PoE 1: сверены по poedb.tw/ru и исправлены на официальные игровые термины все сюжетные объекты («расшатанная свеча», «машина картоходца», «тайник контрабандиста», «рабыня», «рычаг», «тележки с топливом», «маяк», «сундук»), убраны временные оранжевые метки [проверить_перевод!];
  - эталон `base/english` и файлы `ru/` полностью собраны и синхронизированы с Exile UI 1.66.0.
- Термины (выбор пользователя): омни-кей, виджет-кей, меню-кей, рестарт-кей, мув-кей, «виджет меню», exclusive = «перехват», cal = «калибр.», variance = «допуск», tldr-tooltips = «разбор модов», betrayal = «синдикат», enchant finder = «намазки».
