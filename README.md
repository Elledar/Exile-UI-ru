# Русский языковой пакет для Exile UI

Цель: чтобы [Exile UI](https://github.com/Lailloken/Exile-UI) работал с **русским клиентом** Path of Exile
(в первую очередь акт-трекер, акт-декодер и импорт из Path of Building), а тексты показывались по-русски.

Это не копия программы, а только папка с файлами перевода — так просит автор Exile UI
([обсуждение №326](https://github.com/Lailloken/Exile-UI/discussions/326)). Программа обновляется как обычно.

## Установка

1. Скопируйте папку `ru` в папку `data` программы, чтобы получилось `Exile-UI\data\ru\client.txt`.
2. Шрифт с русскими буквами. В родном шрифте программы (Fontin SmallCaps) кириллицы нет. Скачайте
   **Fontin Sans CR Small Caps** (файл `FontinSansCR-SC.ttf`, автор Jos Buivenga, exljbris; ищется по названию),
   переименуйте в `alt_font_FontinSansCR-SC.ttf` и положите прямо в `Exile-UI\data\` (рядом с `Fontin-SmallCaps.ttf`).
   Программа подхватывает файл `alt_font…` сама, устанавливать его в Windows не нужно. В пакет шрифт не входит:
   его лицензия не разрешает распространять файл. Чтобы вернуть родной шрифт, удалите `alt_font…` и верните
   в `ru\UI.txt` и `ru\client.txt` строку `system_font = "Fontin SmallCaps"`.
3. В игре выберите русский язык (в настройках игры) и перезапустите Exile UI.

Программа сама определяет язык игры по её настройкам (`language=ru`) и подхватывает папку `data\ru`.

Затем в настройках программы (раздел General → Language) выберите `RU`. Это язык окон программы, и в PoE 1
от него же зависят названия локаций и камней в акт-трекере. Пока окна остаются английскими (перевод `UI.txt` —
этап 3), но названия в трекере уже русские.

Почему в папке лежат английские копии `UI.txt` и гайдов: при языке окон `RU` программа берёт гайд акт-трекера
только из папки `ru` (без запасного варианта на английский), а без `UI.txt` не даёт выбрать `RU` вовсе.

## Что готово

| Этап | Состояние |
|---|---|
| 1. Запуск на русском клиенте (журнал игры: уровень, `/whois`, смерть, NPC лиг, комнаты Лабиринта) | готово, проверено в PoE 1: клиент принят, класс и уровень определяются, акт-трекер переключает шаги, акт-декодер работает |
| 2. Русские названия локаций и камней (PoE 1) | готово, проверено в PoE 1 (со шрифтом Fontin Sans CR SC): 159 локаций, 470 камней из данных игры; 156 локаций сверены с журналом русского клиента — совпали все |
| 3а. Гайд акт-трекера PoE 1 и квесты | акты 1–3 переведены (ждут проверки в игре); квесты (16) русские во всём гайде, в `gems.json` и `client.txt`; акты 4–10 — текст пока английский |
| 3б. Окна программы (`UI.txt`) | переведены только служебные слова гайда (убить, взять:, купить камни); остальное — английская копия |
| 4. Скрипт сверки после обновлений Exile UI | не начато |

Пока на английском: строки для предметов (Ctrl+C), Ворон, Безымянный провидец, Привои, наёмники лиги.

Названия сверены с poedb (ru/us): Отморозок (Hailrake), Фиделис, Скорбящий (Fidelitas), Ларец алхимика
(Chemist's Strongbox), Бессмертная преграда (Undying Blockage). Не найдены в открытых базах — это надписи на объектах
в локациях, нужно сверить в игре: решётка в Трущобах (grating, акт 3) и свеча в Библиотеке (loose candle, акт 3).

## Установка скриптом

```
python tools/install_ru.py "<папка Exile UI>"
```

Копирует `ru` в `data\ru` и создаёт копии картинок-подсказок акт-трекера под русскими именами (картинки автора
в пакет не входят, копируются внутри вашей установки). Новый гайд подхватывается после сброса прогресса трекера:
зажать кнопку «‹» на 1 секунду (или заново импортировать PoB).

## Инструменты

- `tools/build_client_ru.py` — собирает `ru/client.txt` из английского шаблона Exile UI; заменяет только проверенные строки.
- `tools/build_names_ru.py` — собирает русские `[leveltracker] areas.json` и `gems.json` по внутренним кодам игры
  из выгрузки данных RePoE (repoe-fork.github.io, английская и русская версии).
- `tools/build_guide_ru.py` — собирает русский гайд: переводит строки по `tools/guide_poe1_ru.json`, переименовывает
  квесты и NPC по `tools/quest_names_ru.json` и проверяет, что все метки разметки сохранились.
- `tools/install_ru.py` — установка в программу (см. выше).
- `tools/check_lang_file.py` — проверяет файл перевода по тем же правилам, по которым его читает программа.
