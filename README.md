# Русский языковой пакет для Exile UI

[Exile UI](https://github.com/Lailloken/Exile-UI) — оверлей для Path of Exile (акт-трекер, акт-декодер, импорт из
Path of Building и многое другое). Этот пакет учит его работать с **русским клиентом игры** и показывает тексты по-русски.

Это не копия программы, а только файлы перевода — так просит автор Exile UI
([обсуждение №326](https://github.com/Lailloken/Exile-UI/discussions/326)). Программа обновляется как обычно.
Сейчас пакет сделан и проверен для **PoE 1**.

## Установка

1. Скачайте архив `Exile-UI-ru-….zip` в разделе [Releases](../../releases) (справа на странице).
2. Закройте Exile UI и распакуйте архив прямо в папку программы (где лежит `Exile UI.ahk`), согласившись
   на объединение папок `data` и `img`.
3. **Шрифт с русскими буквами.** В родном шрифте программы кириллицы нет. Скачайте **Fontin Sans CR Small Caps**
   (файл `FontinSansCR-SC.ttf`, автор Jos Buivenga, exljbris; ищется по названию), переименуйте в
   `alt_font_FontinSansCR-SC.ttf` и положите в папку `data` программы (рядом с `Fontin-SmallCaps.ttf`).
   Устанавливать его в Windows не нужно. В пакет шрифт не входит: лицензия не разрешает его распространять.
4. Включите в игре русский язык и запустите Exile UI. Программа сама увидит русский клиент.
5. В настройках программы: **General → Language → RU** (язык окон, названий локаций и гайда).
6. Если акт-трекер уже был запущен на английском — сбросьте его прогресс: зажмите кнопку «‹» на 1 секунду
   (или заново импортируйте билд из PoB).

Версия пакета совпадает с версией Exile UI, для которой он собран (указана в имени архива). Если программа
обновилась, а пакет ещё нет — всё продолжит работать, просто новые строки будут по-английски.

## Что переведено

| Что | Состояние |
|---|---|
| Работа с русским клиентом: уровень, `/whois`, смерть, реплики NPC лиг, комнаты Лабиринта | готово, проверено в игре |
| Названия локаций (159) и камней (470) в акт-трекере — из данных самой игры | готово, проверено в игре |
| Гайд акт-трекера PoE 1, все 10 актов (629 строк), квесты, 26 картинок-подсказок | готово; акт 1 проверен в игре, остальные ждут проверки |
| Окна и настройки акт-трекера и акт-декодера, 83 всплывающие подсказки | готово, настройки проверены в игре |
| Сверка после обновлений Exile UI | готово (для разработчиков, см. ниже) |

**В работе / пока по-английски:**
- остальные модули программы (Item-info, Map-info, Chat macros, Stash-ninja и другие) — окна и настройки;
- гайд акт-трекера для PoE 2;
- строки для предметов (Ctrl+C), Ворон, Безымянный провидец, Привои, наёмники лиги.

Нужно сверить с игрой названия нескольких объектов в гайде: решётка в Трущобах и свеча в Библиотеке (акт 3),
рычаг (акт 4), тележки с топливом и маяк (акт 6), картографическое устройство (акт 7), тайник контрабандистов (акт 8).
Если видите в игре другое название или ошибку — создайте [issue](../../issues) со скриншотом.
Обсуждение пакета в разделе переводов Exile UI: [тема №835](https://github.com/Lailloken/Exile-UI/discussions/835).

В строках гайда вида `lilly: <квест>` имя Лилии оставлено латиницей: программа ищет его буквально в своём коде.

## Для разработчиков

Пакет собирается скриптами (нужен Python 3) из английских файлов Exile UI и таблиц перевода в `tools`:

```
python tools/build_all.py "<папка Exile UI>"      — собрать ru/ и установить в программу
python tools/make_release.py "<папка Exile UI>"   — собрать архив для Releases (.tmp/release)
```

### После обновления Exile UI

Программа обновляется сама, а перевод собирается из `base/english` — английских файлов той версии, по которой он
сделан (копия файлов Exile UI, лицензия MIT — `base/LICENSE.md`). Поэтому обновление ничего не ломает молча:

```
python tools/check_update.py "<папка Exile UI>"
```

Отчёт (и копия в `.tmp/update_report.txt`) показывает, что автор добавил, изменил и удалил в интерфейсе, журнале игры,
гайде, подсказках, локациях и камнях, и что из этого уже переведено. Значок ⚠ — опасные места: перевод съедет
(повторяющиеся ключи UI.txt подставляются по порядку) или сборка остановится. Дальше: поправить таблицы в `tools`,
затем `check_update.py "<папка>" --accept` (с опасными местами — только `--accept --force` после правки),
затем `python tools/build_all.py "<папка>"` — сборка всего пакета и установка.

### Инструменты

- `tools/check_update.py` — сверка с новой версией Exile UI и обновление эталона `base/english` (см. выше).
- `tools/build_all.py` — собирает весь `ru/` из `base/english`, проверяет и (если указана папка) устанавливает.

- `tools/build_client_ru.py` — собирает `ru/client.txt` из английского шаблона Exile UI; заменяет только проверенные строки.
- `tools/build_names_ru.py` — собирает русские `[leveltracker] areas.json` и `gems.json` по внутренним кодам игры
  из выгрузки данных RePoE (repoe-fork.github.io, английская и русская версии).
- `tools/build_guide_ru.py` — собирает русский гайд: переводит строки по `tools/guide_poe1_ru.json`, переименовывает
  квесты и NPC по `tools/quest_names_ru.json` и проверяет, что все метки разметки сохранились.
- `tools/build_ui_ru.py` — собирает `ru/UI.txt` из английского шаблона по таблице `tools/ui_ru.json`
  (проверяет подстановки `#` и переносы `;`).
- `tools/build_help_ru.py` — собирает `ru/help tooltips.json`: английский шаблон + переводы из
  `tools/help_tooltips_ru.json` (проверяет вложенность и разметку подсказок).
- `tools/install_ru.py` — установка `ru/` в программу и копии картинок-подсказок под русскими именами.
- `tools/make_release.py` — архив для игроков: `data/ru` + картинки-подсказки, распаковывается прямо в папку программы.
- `tools/check_lang_file.py` — проверяет файл перевода по тем же правилам, по которым его читает программа.

## Лицензии

Таблицы перевода и скрипты — этого проекта. В `base/` лежат английские файлы Exile UI, а в архиве для игроков — копии
картинок-подсказок акт-трекера: это материалы Exile UI (автор Lailloken), лицензия MIT, см. `base/LICENSE.md`.
Названия локаций и камней взяты из данных игры через [RePoE](https://repoe-fork.github.io). Шрифт в проект не входит.
