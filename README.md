# Русский языковой пакет для Exile UI

Цель: чтобы [Exile UI](https://github.com/Lailloken/Exile-UI) работал с **русским клиентом** Path of Exile
(в первую очередь акт-трекер, акт-декодер и импорт из Path of Building), а тексты показывались по-русски.

Это не копия программы, а только папка с файлами перевода — так просит автор Exile UI
([обсуждение №326](https://github.com/Lailloken/Exile-UI/discussions/326)). Программа обновляется как обычно.

## Установка

1. Скопируйте папку `ru` в папку `data` программы, чтобы получилось `Exile-UI\data\ru\client.txt`.
2. В игре выберите русский язык (в настройках игры) и перезапустите Exile UI.

Программа сама определяет язык игры по её настройкам (`language=ru`) и подхватывает папку `data\ru`.

## Что готово

| Этап | Состояние |
|---|---|
| 1. Запуск на русском клиенте (журнал игры: уровень, `/whois`, смерть, NPC лиг, комнаты Лабиринта) | готово, ждёт проверки в игре (PoE 1) |
| 2. Русские названия локаций, камней, квестов | не начато (названия локаций собраны из журнала игры) |
| 3. Перевод гайда и окон акт-трекера | не начато |
| 4. Скрипт сверки после обновлений Exile UI | не начато |

Пока на английском: строки для предметов (Ctrl+C), Ворон, Безымянный провидец, Привои, наёмники лиги.

## Инструменты

- `tools/build_client_ru.py` — собирает `ru/client.txt` из английского шаблона Exile UI; заменяет только проверенные строки.
- `tools/check_lang_file.py` — проверяет файл перевода по тем же правилам, по которым его читает программа.
